Play Simi — round 4 implementation and verification
Date: 6 October 2026
Production: https://playsimi.danielquek.com
Final deployed Worker version: 8bb2c121-3b4f-4f48-bb15-25a1a5b7bb3f

PHASES
1 — Safety
Accepted mutual friends can visit/join; explicit room codes remain available. Removed visit XP. Stranger profiles omit live status/activity/location; the friend picker contains friends and pending requests. Block, Mute and Report are separate actions with Cancel. Block removes avatars and stops invitations; Mute suppresses emotes. New guests retain generated names; verified account handles pass a Unicode-normalized profanity/contact/name-pattern filter. Added nickname hint, optional email guardian notice and expandable privacy notice. Under-18 purchases explain why disabled. Privacy deletion has danger styling, confirmation and Cancel. Guest account UI has consistent 30-day session copy and no Sign out.
2 — Reliability
All seven game finish paths use a durable, owner-scoped outbox, automatic backoff and offline recovery. Server finishes remain valid for 24 hours; starting another game no longer abandons queued earlier results. Finish retries remain idempotent. Stale client snapshots clear after 15 seconds; first connection retries quietly. Header separates players from NPC neighbours. Capped nameplates; retained movement latch/first-click handling and novice race-again rules. Performance fallback explains itself once and offers Switch back.
3 — Characters
Hat-safe hair hides the crown while preserving fitted sides/back. Full hair remains for non-covering class equipment. Fixed the server guest sanitizer that incorrectly reset new free hair IDs to blue default. CPU racers use varied seeded identities; iris tint is now fully applied. Closed eyes use skin-tone lids. Class cape clasps are larger; Thief has long rear scarf tails and shorter curved daggers. Existing cape sway retained.
4 — Arcade
Daytime pastel cabinet/frame replaces dark arcade treatment. Hop Hop uses the player's avatar; Star Swarm has their head in the cockpit; Brick Bash has an avatar paddle badge; Noodle Run has a noodle face. Hop Hop has a pre-run countdown. New Star Swarm rounds require input and end at zero after eight idle seconds; legacy replay seeds retain compatibility. Fishing gives LET GO cues. Zero scores get retry copy without confetti. Improved landscape layout, intro covers and label contrast; hide Coast Rush's ghost title. Closing a game returns to Games page 1.
5 — Shop, world and phone polish
Premium cards use the same cached avatar render pipeline as wardrobe sets. Enlarged CLAIM controls, styled settings/selects/links and labelled rotation controls. Kopi awards its quest after the registered scratch even if Esc ends the remaining animation. Auto-walk is faster; activities already within reach start without Walking over. Personal-best section covers all seven games and uses accurate all-time wording alongside daily rankings. Make it yours uses the correct title/current name. Portrait and landscape HUD/joystick fixes; wardrobe preview/actions fit landscape and coordinate try-on preserves scroll.

LIMITS / NOT FULLY VERIFIED
This is not an assertion that every acceptance item passed on screen. The following still need broader device/visual QA:
- Every hat crossed with every hairstyle was not rendered; class headwear and representative try-ons were inspected.
- Every screen in both phone orientations was not exhaustively visited; priority layouts were checked.
- Real sustained physical keyboard holds could not be generated by the available browser controller. Native taps and existing automated movement/replay tests passed.
- No mid-range physical-phone 60fps/4G/100ms benchmark was performed.
- The requested softer performance-mode ground replacement was not implemented; current low mode retains antialiased rendering and reduces pixel ratio/shadows. The reported pixelated fallback needs reproduction on an affected device.
- Seven-game automatic retry behavior is tested, but not seven complete manual on-screen rounds.
- Daily personal bests are now accurately labelled as all-time personal bests; Hoops/Fishing appear there, not as new ranked daily leaderboards.
- Nickname filtering is heuristic, not a guarantee of detecting every real name or profanity in every language.
